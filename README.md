📱 Project Title

Online Mobile Shop Website

📖 Project Description

The Online Mobile Shop Website is a college project developed to provide an online platform where users can explore and purchase mobile phones conveniently.

The website displays different mobile phones along with their details, allowing users to browse products and get information about available mobiles. The project demonstrates the basic concepts of web development and online shopping systems.

🎯 Project Objectives
To develop an easy-to-use online mobile shopping website.
To display mobile phones and their details in an organized manner.
To provide users with a convenient way to browse mobile products.
To understand the working of an e-commerce website.
To apply web development concepts in a real-world project.
✨ Features
🏠 Home page
📱 Mobile phone product listings
🔍 Product browsing
📋 Mobile phone details
🛒 Online shopping interface
👤 User-friendly interface
📞 Contact/Support section
🛠️ Technologies Used
HTML
CSS
